# AI 工程师学习计划

大模型应用开发方向 · 12 周 · 从基础到实战

## 项目简介

一个面向有编程基础的开发者的 **LLM 应用开发**学习计划，包含完整的 12 周课程大纲和一个交互式 Web 学习平台。

### 学习目标

掌握大模型应用开发的核心技能，能独立搭建端到端的 LLM 应用（RAG、Agent、API 服务）并部署上线。

### 学习周期

4 个阶段 × 3 周：

| 阶段 | 内容 | 周数 |
|------|------|------|
| 一 | AI 项目工程化与 LLM 核心概念 | 第 1-3 周 |
| 二 | RAG 与向量数据库 | 第 4-6 周 |
| 三 | Agent 智能体开发 | 第 7-9 周 |
| 四 | 部署上线与综合实战 | 第 10-12 周 |

## 交互式学习网站

直接用浏览器打开 `index.html` 即可使用，无需安装任何依赖。

### 功能特性

- **进度追踪** — 每周任务勾选，全局进度可视化
- **学习计时** — 每周独立计时器，记录学习时间
- **深度弹窗** — 点击"深入学习"卡片展开详细内容
- **权威资料** — 每周精选高质量学习资源链接
- **笔记功能** — 每周独立笔记区域
- **日期规划** — 设置开始日期，自动计算每周时间
- **深浅模式** — 支持暗色 / 亮色主题切换
- **本地存储** — 所有数据保存在浏览器本地

## 主题覆盖

- Prompt Engineering（含推理模型新范式）
- RAG 管线（文档加载 → 分块 → Embedding → 检索 → 生成）
- 向量数据库（PGVector、FAISS、ChromaDB）
- GraphRAG 与混合检索
- LangChain / LlamaIndex 框架
- Agent 架构（ReAct、Plan-and-Execute、Reflection）
- MCP（Model Context Protocol）
- AI 可观测性（LangSmith、Langfuse）
- 模型治理与多模型路由
- 生产部署与 API 服务化
